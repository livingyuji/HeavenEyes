# SECURITY POLICY — HEAVEN EYES

### 1. Supported Versions

Security updates and vulnerability patches are actively maintained for the following versions:

| Version | Supported          | Target Platform |
|---------|--------------------|-----------------|
| 1.0.x   | :white_check_mark: | Paper 1.21.x    |

---

### 2. Reporting Vulnerabilities

If you discover a security vulnerability in Heaven Eyes — such as an anti-cheat bypass, privilege escalation flaw in the LuckPerms integration, memory exhaustion attack, or data integrity issue — please report it responsibly.

**Please do NOT file public GitHub issues for security vulnerabilities.**

Instead, report the issue privately to the project creator:
- **Author:** LivingYuji
- Include detailed reproduction steps, server environment details (Paper build, Java version), and configuration dumps.
- If demonstrating a bypass, provide sanitized network traces or test logs.

---

### 3. Vulnerability Response Timeline

- **Initial Acknowledgment:** Within 48 hours of receipt.
- **Triage & Assessment:** Severity assessment and validation within 5 business days.
- **Remediation & Patch Release:** Critical vulnerabilities are addressed in prioritized hotfix releases.
